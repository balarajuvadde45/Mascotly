How it works

Mascotly builds its own brain — you never write flows or training data.

1📚

Feed it your app

Docs URLs, sitemap crawls, GitHub repos, uploaded files, pasted text, review dumps. The crawler is robots-aware; GitHub ingestion reads README + docs trees.

2🧠

The analyzer studies it

An LLM map-reduce (or a fully offline extractive engine) synthesizes an app profile — purpose, features, limitations, FAQs — that becomes the mascot's identity, with starter questions.

3⚡

Embed one tag

A dependency-free Web Component appears in any framework. Streaming answers, citation chips, starter suggestions, host actions, escalation — all style-isolated by Shadow DOM.

Everything included

A complete assistant platform, not just a chat bubble.

🔎

Hybrid retrieval

BM25 fused with TF-IDF cosine vectors out of the box — zero external services. Add OpenAI-compatible or Ollama embeddings when you want semantic search.

🧩

Host actions

Register functions in your app and the mascot triggers them mid-conversation — navigation, dialogs, ticket drafting — through a safe, validated JSON protocol.

🔌

Any LLM

OpenAI-compatible APIs (OpenAI, Groq, Together, vLLM, LM Studio), Anthropic, Ollama — plus a deterministic offline brain for CI, demos and air-gapped use.

🛡

Production safety

Per-app keys, origin allowlists, sliding-window rate limits, timing-safe auth, escape-first rendering, sandboxed subprocess execution for REA.

🧾

Full visibility

Admin dashboard with session transcripts, escalation flags, feedback ratings, retrieval testing, job progress, per-app model overrides and key rotation.

🔬

REA integration

Point Mascotly at an Electron bundle, ASAR archive or JS tree: the Reverse-Engineering-Anything CLI extracts modules, entry points and features into knowledge.

Install through your agent

Mascotly ships an MCP server and an agent skill — Claude Code, Codex, Cursor, Windsurf and Gemini CLI can set everything up for you.

git clone https://github.com/morluto/mascotly && cd mascot
npm install

# register the Mascotly MCP server with Claude Code (creates a backup first)
node bin/mascot.js setup --client claude_code --install-skill

# then just ask your agent:
#   "Add a mascot to my app at ~/projects/myapp" ← it does the rest

Agents get tools like mascot_create_app, mascot_add_source, mascot_analyze and mascot_embed_snippet — the full workflow from docs ingestion to embed snippet.

Forge: give us a repo, get a mascot

Point Mascotly at any repository — public, or yours with a GitHub token. It ingests the code and docs, designs the mascot's identity and skills, and hands you the embed snippet or a deployed URL.

Deploy

Serverless or self-hosted — same codebase, one environment switch.

▲ Vercel SERVERLESS

  1. Push the repo to GitHub and import it in Vercel — zero config (vercel.json included).
  2. Add a Vercel KV store (Marketplace → KV) — Mascotly auto-detects it for persistent storage.
  3. Optional env: MASCOT_LLM_API_KEY, MASCOT_ADMIN_KEY, GITHUB_TOKEN.
  4. Deploy. The dashboard, widget CDN and API are live on your domain.

Note: long crawls and REA need the self-hosted mode; on serverless they are capped.

🐳 Docker / VPS FULL MODE

  1. docker compose up — or npm start on any Node ≥ 18 host.
  2. File-backed storage with atomic writes; back up the data/ directory.
  3. Unlimited crawl depth, background jobs, and full REA reverse engineering.
  4. Put nginx/Caddy with TLS in front; disable proxy buffering for SSE.

Same dashboard, same widget, same API — switch by moving the workload.

FAQ

Everything else you might be wondering.

Does it work without any LLM API key?

Yes. Mascotly ships a deterministic offline brain: answers are composed from retrieved knowledge with citations, the analyzer runs an extractive engine, and retrieval is fully local (BM25 + TF-IDF vectors). Add any OpenAI-compatible, Anthropic or Ollama endpoint when you want conversational depth.

Where does my data live?

Wherever you deploy. File mode keeps everything in a data/ directory you control; serverless mode uses your own Vercel KV / Upstash instance. Mascotly phones home to nobody.

How does it avoid making things up?

Answers are grounded in retrieved knowledge with inline [n] citations; the prompt forbids invention, unknowns are stated honestly, and the retrieval tester lets you audit exactly what the mascot knows.

What is REA integration?

REA (Reverse Engineer Anything) analyzes shipped artifacts — Electron bundles, ASAR archives, JavaScript trees — locally, without source. Mascotly folds its findings (modules, entry points, stack, features) into the mascot's knowledge. See morluto/rea.
